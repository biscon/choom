Room clutter kit: 32 individual glTF + BIN models and eight shared PNGs.

Copy this complete folder with textures/. Units are meters, +Y up. Tabletop print faces +Y; wall print faces +Z.

Base color is sRGB. Normals are OpenGL Y+ linear. ORM is linear R=AO, G=roughness, B=metallic.

Book_1984_Readable has the gameplay number on cover and spine. Generic book/note writing is deliberately nonsemantic; popup text is supplied by the engine.

See ../../README.md for dimensions, sources and import notes.
