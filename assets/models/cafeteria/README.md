# Cafeteria glTF kit

25 separate models, 24,992 triangles total. Keep each `.gltf` beside its matching `.bin`, and keep the shared `textures/` directory here. Cache textures by resolved path to share GPU memory across assets.

Metres; +Y up, +Z front; bottom pivots. Normal maps are OpenGL Y+. Basecolor is sRGB; ORM and normals are linear. ORM channels: R occlusion, G roughness, B metallic. No separate roughness maps. No lamps or fixtures are included.

See `../../README.md` and `../../manifest.json` for dimensions and placement notes.
