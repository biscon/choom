Storage room kit: 26 glTF + BIN assets, 20 shared PNGs.

Copy this whole folder, preserving textures/ paths. Units are meters, +Y up.
Base color is sRGB; normal maps are OpenGL Y+ linear; ORM is linear R=AO, G=roughness, B=metallic.
The pallet jack is static with lowered forks; the vise and tools are separate props.
Full asset dimensions and notes are in ../../README.md and ../../manifest.json.
