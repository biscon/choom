# Keys and access cards

11 independent glTF models with matching BIN files and 6 shared PNG textures. Keep `textures/` beside the models. Cache resolved image paths to share textures across assets.

Metres, +Y up, key tips +X, card fronts +Y. Bottom-centered pivots for laying pickups on surfaces. Basecolor is sRGB; ORM and normals are linear. ORM = R occlusion, G roughness, B metallic. Normal maps are OpenGL Y+.

See ../../README.md and ../../manifest.json for dimensions and material details.
