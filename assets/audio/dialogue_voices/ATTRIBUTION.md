# Dialogue Voice Attribution

Character vocalizations in this directory were generated using OpenAI
text-to-speech (`gpt-4o-mini-tts`, initially using the built-in `onyx` and `nova`
voices). These are AI-generated voices, not recordings of human actors.

Generation configuration, source fragments, and asset provenance are maintained
in `tools/dialogue_voice_generator/`. Audio was prepared offline with FFmpeg.
